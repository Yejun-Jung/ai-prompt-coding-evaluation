# 🎬 CineLog (나만의 영화 리뷰 다이어리)

CineLog는 내가 본 영화의 평점과 감상평을 기록하고 관리할 수 있는 **React 기반 싱글 페이지 애플리케이션(SPA)**입니다.
프리미엄 OTT 서비스가 연상되는 모던한 다크 테마와 매끄러운 애니메이션 인터랙션을 통해 최고의 사용자 경험(UX)을 제공합니다.

<br/>

## ✨ 주요 기능 (Features)

- **리뷰 작성 및 수정 (CRUD)**
  - 영화 제목, 장르, 관람일, 별점(0.5점 단위), 감상평을 입력해 리뷰를 등록할 수 있습니다.
  - 기존에 작성한 리뷰를 언제든 다시 폼으로 불러와 내용을 수정할 수 있습니다.
- **실시간 검색 및 필터링**
  - 영화 제목이나 장르 키워드를 입력해 내가 남긴 리뷰를 즉시 찾아볼 수 있습니다.
- **다양한 정렬 옵션**
  - 최신 관람순, 오래된 관람순, 별점 높은 순, 별점 낮은 순으로 리뷰 목록을 정렬합니다.
- **데이터 영구 보존 (LocalStorage)**
  - 브라우저의 로컬 스토리지를 활용하여 새로고침을 하거나 창을 닫아도 리뷰 데이터가 안전하게 유지됩니다.
- **반응형 웹 UI (Responsive Design)**
  - 데스크톱에서는 폼과 리스트가 좌우로 분할되는 구조, 모바일에서는 하단 탭 바를 이용해 화면을 전환하는 등 디바이스에 최적화된 레이아웃을 제공합니다.
- **프리미엄 UI/UX 디테일**
  - 글래스모피즘(Glassmorphism), 네온 글로우 효과, 둥근 커스텀 스크롤바, 로고 애니메이션 등을 적용하여 트렌디하고 고급스러운 디자인을 구현했습니다.

<br/>

## 🛠 기술 스택 (Tech Stack)

- **Frontend:** React, Vanilla CSS
- **Build Tool:** Vite
- **Fonts:** Outfit(영문/숫자), Pretendard(한글)
- **Deployment:** Vercel (또는 Netlify)
